# Numera 品牌迁移记录

## 迁移概述

本项目完成一次品牌迁移：

- 旧名称：`fish-cat-speed-math`
- 新中文正式名：**数感**
- 新英文名：**Numera**
- 小名：**算算**

当前正式仓库：

`JIDAIN/numera`

## 迁移原则

本次迁移只调整品牌标识，不改变项目的数据模型和历史兼容关系。

保留以下内容：

- Git 历史提交中的旧名称
- 历史开发记录中的旧名称
- 迁移说明中的旧名称
- 数据结构中的历史兼容字段

不进行机械全文替换。

## 已完成迁移内容

- GitHub 仓库名称迁移至 `numera`
- README、项目说明统一使用「数感 / Numera」
- package name 更新为 `numera`
- 当前 UI 展示名称统一使用新品牌

## 部署说明

- Vercel 项目名称应保持为 `numera`
- 原生产访问 URL 保持不变
- 不因品牌迁移修改生产域名

原因：

- 避免已有访问链接失效
- 保留用户访问入口稳定性
- 品牌名称与部署 URL 不强绑定

## 数据兼容说明

品牌迁移不会影响：

- 用户账号
- 历史训练数据
- 数据库记录
- IndexedDB 历史记录
- 导出数据格式

## 后续维护规则

新的开发文档、代码注释、UI 文案统一使用：

- 数感
- Numera
- 算算

旧名称仅允许出现在：

- 历史记录
- 迁移说明
- 兼容说明
