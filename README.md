## 当前正式能力

- 登录账号固定映射为 🐟 或 🐱；训练归属由 Auth 账号决定，界面身份不能改变云端归属。
- completed 训练先保存 IndexedDB，再尝试幂等同步 Supabase；结果页和历史页显示同步状态，当前账号可手动重试，配对对象记录只读。
- 云端历史仅对本人及配对对象开放，并与同 ID 的本地记录去重；登录前旧 completed 历史必须由用户选择合并或丢弃。
- active 训练从不上传，只存当前浏览器。页面隐藏、失焦、锁屏、冻结、`pagehide`、浏览器返回/前进、关闭/跳转及恢复读取都会暂停计时；BFCache 恢复不补计离开间隔。每个账号和未登录本地范围各自最多一条 active。
- 趋势按“用户 + 题型 + 子模式 + 实际题量”隔离；多位数直除使用 `2.6.0` 生成规则，以实际题面满足商结构和可行的除数位数联合配额。
- 历史页默认显示本人记录，可查看配对对象的只读共享记录；按实际存在的题型/子模式筛选，并提供加权正确率、平均单题用时、等级分布和逐条同步状态。统计口径见 [HISTORY_REPORTING.md](./HISTORY_REPORTING.md)。
- 异步 PK：普通训练结算后可向固定配对对象发起同题同序挑战；个人训练长期归档，PK 页面只展示近 7 日激励结果。红/蓝气泡、权限、同步和分页规则见 [PK_ASYNC.md](./PK_ASYNC.md)。

- 等级评定标准与版本兼容规则见 [RATING_STANDARDS.md](./RATING_STANDARDS.md)。

## 当前已实现

- 两名固定用户：🐟 小鱼、🐱 小猫。
- 9 类基础题型：整数加减、两位数乘法、有效位直除、多位数相加、分数—百分数转换、分数比较。
- 首页提供 10 个清晰的一级训练入口：“分数转百分数”和“百分数转分数”独立展示，但仍复用同一底层题型及各自答题规则；“三位数÷两位数”选中后才显示商首位、商前两位和 3% 估算三个紧凑子选项。
- 浏览器内出题、自动判题、单题/整组有效计时、后台自动暂停、暂存与刷新后恢复。
- 手机竖屏训练页采用 `100dvh` 单屏布局：题目、计时、答案、草稿入口、重开和完整键盘同时可见；键盘避让 iPhone 底部安全区，页面锁定仅作用于训练页。
- 统一计算器式数值键盘：`± / 清空 / 退格 / 数字 / 小数点 / 确定`；分数比较使用左右竖式分数、中间关系符号和“大于/小于”大按钮。分数转百分数以“分数 ≈ ___%”直接输入百分数；百分数转分数以标准上下分数和一条分数线展示答案位，首次在分子输入一个数字后自动切到分母，手动点回分子后可持续修改且不再自动跳转；当前输入位会显示清晰的浅绿底与深绿描边。
- 两个转换方向共用 46 条固定高价值百化分关系（21 个单位分数、25 个常见非单位最简分数），不再混入接近基准或普通直除随机题；题组各半覆盖两类关系，类别题库用完前不重复。分数转百分数只接受预设百分数，百分数转分数只接受题库中的最简分数。
- 新分数比较题只生成不相等的两个分数，并统一以半角 `< / >` 保存和判题；旧版已完成的等值题与全角符号记录仍可正常查看。
- 训练页空答题框保持纯空白，不再显示横线占位；数字键盘右下角“确定”使用与“清空”一致的深绿色文字，左上角保留“暂存”。
- 临时手写草稿：可在深绿、黑、红、蓝四色画笔之间切换，并支持一键清空和关闭；不识别、不上传、不保存。
- 结算页、题目明细、按日期和用户查看的历史记录；结算与历史详情的“草稿”入口会悬浮在可视区域内，滚动到后续错题时仍可随时打开草稿复盘。手机窄屏中的长题目会完整换行并独占第一行，作答、判定、正确结果和用时排列在第二行；桌面端继续使用六列表格。
- 每种题型、答题规则与用户独立的成长趋势。全部历史记录会参与趋势；记录较多时会按时间顺序自动汇总，保留长期走势。
- 题目生成公共契约：生成器版本、可注入随机源和 ID 工厂、有限重试/确定性回退；旧题缺少结构字段时安全标记为 `legacy_unknown`。
- 两位数加减结构化题组：无进借位 10%、单次进借位 60%、边界挑战 30%；边界挑战为跨百加法或结果为个位数的减法，所有 10～100 整十题量均按精确配额生成。
- 三位数加减结构化题组：无进借位 10%、一次进借位 60%、两次连续进借位 30%；按个位和十位的真实进借位次数分类，且不产生千位进位或负数结果。
- 两位数×一位数结构化题组：无进位 10%、一次进位 40%、两次进位 50%；乘数 8、9 会作为客观的高乘数辅助标签保存。
- 两位数×两位数结构化题组：接近整十 30%、11～19 因子 20%、个位较小便于拆分 20%、普通题 30%；使用固定优先级保证主结构互斥。
- 多位数相加固定为 4 个三位数：单列进位 10%、双列进位 25%、三列连续进位 40%、高进位量 25%；不生成无进位、减法、三项相加或四/五位数混合题。
- 三位数÷两位数：商 1～10 占 25%、商 10～100 占 35%、首位误导占 20%、接近整数边界占 20%；支持商首位、商前两位和 3% 估算，且新题不生成整除式。
- 分数比大小：直接判断 10%、同向变化 40%、接近二分之一 20%、一般比较 30%；左右均为不相等的真分数，答案只含 `< / >`。
- 题量选择：快速模式固定 10 题、标准模式固定 20 题；自定义模式可选 10～100 题（每次增加 10 题，首次默认 30 题）。

## 当前边界

- 数据仅保存于当前浏览器的 IndexedDB；换设备、清除浏览器数据后不会自动恢复。
- 尚未实现登录、云同步、异步 PK、正式离线缓存和应用商店安装包。
- 九类基础题型均已有主结构生成；多位数直除的五种商结构已完成，但三/四/五位除数 75%/15%/10% 的最终题面配额仍待修复。专项训练、浏览器 E2E、真机与 PWA 验证尚未实施。

## 自动化测试

测试使用 Vitest、React Testing Library 和 `fake-indexeddb`，不依赖真实浏览器数据库。

- 会话交互：新建、继续、放弃、取消、单一 active 约束与刷新恢复；
- 重开训练：沿用当前训练冻结的用户、题型、答题规则和题量，直接舍弃旧进度并生成新的会话与完整题组；重复点击受保护，旧版题目重开次数仅保留数据兼容，不再在完成详情中展示；
- 计时：暂存、前后台切换、多次恢复、重复提交保护；
- 历史：日期切换、双用户分区、详情入口、1/10/100/1000 条趋势聚合；
- 存储：真实 fake IndexedDB 的创建、更新、完成、放弃、旧记录兼容与失败提示。
- 题量：10～100 的运行时校验、快速/标准/自定义模式、取消保护、active 持久化、评级缩放与配额总数。
- 两位数加减：结构分类、所有合法题量的精确配额、答案与原始数据一致性，以及固定生成上下文复现。
- 三位数加减：逐位进借位分类、所有合法题量的精确配额、答案与原始数据一致性，以及固定生成上下文复现。
- 两位数×一位数、两位数×两位数：真实进位/策略分类、所有合法题量的精确配额、低价值题过滤与固定生成上下文复现。
- 多位数相加：4 个三位数约束、逐列进位分类、全部合法题量的精确配额、进位元数据、答案和固定生成上下文复现。

当前九类基础题型均已有可验证主结构；正式训练通过 `generateSet()` 生成完整题组，结构比例不以单题辅助入口 `generateQuestion()` 的抽样结果为准。除多位数直除的除数位数二级配额外，其余八类题型的代码与当前规则文档一致。分数—百分数转换只覆盖固定百化分关系，不再生成随机接近基准或普通直除题。

多位数直除当前能保证商小于 1、1～10、10～100、100 以上和接近整数边界五种主结构的题组配额；但商结构和除数位数按索引配对会产生不可行组合，备用题随后改变除数位数，因此最终题组尚不能保证三位 75%、四位 15%、五位 10%。该问题已记录为开发任务 1.8.1，本轮未修改生成器。

三位数÷两位数的 3% 估算模式要求输入近似商，以真实商为基准计算相对误差，误差不超过 3%（含边界）即判定正确；新题会排除整除式，确保保留估算训练价值。结算明细将“判定”和“正确结果”分列，3% 模式的正确结果固定显示真实商四舍五入后的两位小数，不显示接受范围。它与商首位、商前两位在历史趋势中分开统计。

## 多标签页说明

开始训练会再次检查 IndexedDB，且同一按钮的快速重复点击会被忽略。当前未提供完整跨标签页锁：两个标签页同时开始时，可能都暂时进入训练；该限制已记录在审查文档和开发计划中。

## 代码质量约束

项目使用严格 TypeScript，`allowJs` 已关闭。IndexedDB 操作集中在 storage 模块；当前没有 Supabase 依赖或占位代码；写入失败会显示应用内错误提示。

旧版本地会话在读取时会经过结构校验并补齐新增字段的默认值；无效记录不会进入训练或历史页面。提交前请运行 format、typecheck、lint、test 和 build。
